# Crate Daily Notes

This directory stores synthesized daily Crate progress notes for vault sync, release prep, and future Codex handoff.

The active during-the-day ledger lives at:

`/Users/bryantfeintuchclaw/Projects/.codex/state/daily-crate-ledger.md`

The nightly vault automation should read that ledger first, then write or update dated notes here and in the compiled vault.

## Rules

- Keep notes synthesized and factual.
- Preserve Bryant decisions, QA classifications, PR/release state, blockers, and next actions.
- Do not paste raw transcripts.
- Do not store tokens, credentials, full Figma URLs, Figma file keys, signed URLs, raw private paths, raw logs, broad file lists, or unrelated client data.

## Suggested Daily Note Shape

- Date
- Active QA/release version
- Smoke tests run
- PASS / FAIL / BLOCKED classifications
- Fixes landed
- PRs opened or merged
- Release gates run
- Bryant product decisions
- Blockers
- Non-blocking follow-ups
- Next recommended action
