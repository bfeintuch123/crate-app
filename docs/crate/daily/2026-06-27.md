## Redesign Simplification Decision

Bryant and Jenna want the redesign to move back toward the simple current Crate app, using the new layout as a visual refresh rather than a source of new terminology or product concepts.

Decision:

- Remove `Home`.
- The sidebar destination for the selected active project should be named `Current Project`.
- Do not use `Files` as the top-level sidebar label because it sounds like a global file browser.
- Do not use `Projects` for that destination because there is already a `Projects` section.
- Keep the Crate app mental model simple: Projects, Current Project, Quick Package, Settings, and Help.

Implementation direction:

- Preserve existing Crate behavior and qa41 package states.
- Avoid introducing new terms unless they directly map to existing behavior.
- Use the new design language to clarify current Crate workflows, not to add new ones.
- Default launch should land on `Projects`.
