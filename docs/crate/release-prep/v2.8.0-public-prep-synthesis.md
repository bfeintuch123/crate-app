## Must Decide Before Final Public Release

### 1. Figma public guidance

Classification: release-note/docs requirement.

Crate works with accessible Pro/team workspace Figma files. Figma API limits and access are affected by file workspace, plan, seat, and file permissions. Starter/Drafts or inaccessible client files may rate-limit or fail closed.

Recommendation:

- Add clear get-crate.com guidance before or alongside release:
  - Figma requires a valid personal access token.
  - Each Crate project needs a project-level Figma link.
  - Current Page Only is default.
  - Entire File is opt-in.
  - Figma files should be in an accessible Pro/team workspace for reliable API access.
  - If Figma rate-limits, Crate will retry later and fail closed for that session.

Detailed Figma guidance should live primarily on get-crate.com, not as heavy app copy. The app should keep concise operational copy and privacy-safe failure states, with an optional lightweight path to learn more.

### 2. Moderate `uuid` audit advisory

Classification: monitored dependency risk, not an immediate blocker.

Current audit state:

- `npm audit --audit-level=high`: passes.
- `npm audit --json`: reports one moderate advisory for `uuid <11.1.1`.
- npm's available fix requires `npm audit fix --force` and installs `uuid@14.0.1`, a SemVer-major upgrade.
- Crate currently imports `uuid.v4()` only in `main.js`.
- The advisory concerns missing buffer bounds checks in v3/v5/v6 when a `buf` is provided; current Crate usage does not exercise that path.

Recommendation:

- Do not force-upgrade during public release prep.
- Document as accepted moderate risk for `v2.8.0`.
- Schedule separate dependency remediation after release, or upgrade deliberately with tests if Bryant wants a stricter public release bar.

### 3. UX caveats

Classification: polish / tester-rollout follow-ups.

Observed caveats:

- PSD pre-package UI shows only the PSD, while Package Complete, Package Details, and disk output correctly include linked dependencies.
- Some lanes show visible UI refresh lag even when local state and package output are correct.
- Illustrator scripted-save automation did not trigger staging until normal foreground `Cmd+S`.

Recommendation:

- Do not block final release on these if Package Review, Package Details, and output remain correct in user workflows.
- Keep as post-release or beta-tester follow-ups unless Bryant wants a stricter review UI before public launch.
