FAQs

USING CRATE

USING CRATE

What does Crate do?

Crate packages the files behind your creative work into one organized project folder. Keep your working files, linked assets, and supporting media together—ready to hand off, save, or return to later.

USING CRATE

Does Crate work with the apps I already use?

Crate supports creative documents from apps including Photoshop, Illustrator, InDesign, Adobe XD, Sketch, Acrobat, PowerPoint, and Keynote. You can also connect Figma to add files from your designs.

What Crate can gather depends on the app, file type, and access to the linked assets.

USING CRATE

Do I need to change how I work?

No. Create a project in Crate, choose where to save it, and keep working in your usual apps. Crate tracks related files while your project is being watched. When you’re ready, review the assets and package your project.

USING CRATE

Can I package a project I’ve already started?

Yes. Quick Package lets you start with an existing supported design file, such as a Photoshop or Illustrator document.

Drop in the file, review the linked assets Crate finds, and package them together. You don’t need to have created a Crate project beforehand. Linked assets must still be accessible for Crate to include them.

USING CRATE

How does Crate keep my work secure?

Crate packages your project files locally on your Mac, into a folder you choose. You review which assets are included and control where the finished package is stored and shared.

Your Figma connection is read-only: Crate retrieves design data and assets without editing your Figma files. Your Figma account’s file permissions still apply.

Saved Figma tokens are encrypted on your Mac with protection backed by macOS Keychain. If secure storage is unavailable, Crate won’t save a new connection.

Figma requests use HTTPS. Crate blocks redirects on authenticated API requests and limits download sizes and request times. Figma diagnostic messages are filtered to remove credentials, private file paths, and request URLs.

You can disconnect Figma in Crate to remove its saved token and stop automatic checks.

FIGMA

FIGMA

How do I connect Figma to Crate?

Create a personal access token in Figma, then connect it in Crate:

  1. In Figma’s file browser, open your account menu and go to Settings → Security.
  2. Under Personal access tokens, select Generate new token and name it Crate.
  3. Enable current_user:read and file_content:read.
  4. Copy the token immediately, then paste it into Crate → Settings → Integrations → Figma Integration and connect.

Keep your token private. Figma only displays it immediately after you generate it.

FIGMA

Where do I add my Figma link?

After connecting Figma, open the page you want to include in the Figma editor and copy its link. Create or open a project in Crate, then add the link using the project’s Figma link control.

Use a design-file link rather than a presentation-only prototype link. Your connected Figma account must have access to the file.

FIGMA

Can I choose which Figma page to include?

Yes. Current Page Only is selected by default, so Crate uses the page referenced in your link. Choose Entire File if you want to include assets from across the file.

You can change the link or selection through Edit Figma Link in your Crate project.

FIGMA

Why isn’t my Figma file connecting?

Check that your token hasn’t expired or been revoked, has the required read permissions, and belongs to a Figma account that can open the file.

If you’re adding a specific page, copy a fresh link from that page in the editor. Figma’s workspace permissions and API limits can also affect access.
